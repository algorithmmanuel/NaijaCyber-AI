# External beta-testing plan — NAIC submission

## Objective
Obtain feedback from at least two independent external testers on the
existing learner interface, tutor usefulness and multilingual quality,
without claiming production readiness.

## Procedure
1. Obtain informed consent and explain that an experimental AI model may
   produce inaccurate advice; do not collect sensitive personal data.
2. Use a supervised test window while the Colab model and tunnel are running.
   Do not leave the temporary endpoint publicly available unattended.
3. Ask each tester to complete the phishing, password and social-engineering
   missions; record whether progress updates and persists after refresh.
4. Ask each tester to submit one synthetic tutor question in English and,
   if qualified, one in a Nigerian language they speak fluently.
5. Record dated results and screenshots without any API keys, private user
   information or active authenticated links.

## Submission evidence
Create a summary documenting the number of testers, task completion,
observed failures, corrections made, and remaining limitations. Store
consented, anonymised records privately. Do not present unreviewed
outputs as validated translations or claim more testers than actually participated.
